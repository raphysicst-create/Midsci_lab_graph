# 조별 실험 그래프 (수업용)

중학교 과학 실험 데이터를 수업 중에 입력하면 그래프로 변하는 과정을
보여주는 프레젠테이션 모음입니다. 인터넷 없이 동작합니다.

## 수업에서 쓰는 법

1. **`dist/index.html`을 더블클릭**해서 열고, 오늘 실험을 고릅니다.
   (파일 하나만 갖고 다니려면 **`dist/total.html`** — 전체 실험이 한 파일에 들어 있습니다.)
2. →/← 키(또는 화면 아래 버튼)로 씬을 넘깁니다:
   도입(축 소개) → 1~6조 입력 → 종합(전체 점 + 추세선).
3. 조별 씬에서 측정값을 입력하고 Enter — 숫자가 그래프 위로 날아가
   점으로 찍힙니다.
4. 종합 씬에서 "추세선" 버튼으로 직선을 그립니다. 조별 칩으로 특정 조를
   껐다 켤 수 있습니다.
5. 입력값은 자동 저장됩니다(새로고침해도 유지). 다음 반 수업 전에
   우상단 **전체 지우기**를 누르세요.

## 새 실험 추가 / 수정

Claude Code를 이 폴더에서 열고 "○○ 실험 앱 추가해줘"라고 하면 됩니다.
직접 하려면 `configs/`에 JSON을 만들고 `py build.py` 실행 — 자세한 규칙은
[CLAUDE.md](CLAUDE.md), 어떤 실험이 가능한지는 [coverage.md](coverage.md) 참조.
